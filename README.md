# Trilha de Pandas

Este repositório reúne todo o material utilizado na gravação da **Trilha de Pandas**, desenvolvida para ensinar análise de dados utilizando Python e Pandas de forma prática e focada no mercado de trabalho.

Mais do que aprender comandos, o objetivo desta trilha é desenvolver uma habilidade fundamental: **aprender a pensar com dados**. Ao longo das aulas, o aluno aprende a explorar informações, formular perguntas, interpretar resultados e utilizar a inteligência artificial como apoio, sem abrir mão do raciocínio.
